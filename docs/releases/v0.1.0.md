## Verificação

- `npm run lint`: aprovado.
- `npm run typecheck`: aprovado em API, web e contracts.
- `npm test`: seis testes aprovados (contrato health, três portas inválidas, origem inválida e CORS configurado).
- `npm run build`: aprovado para API e web.
- `npm audit`: zero vulnerabilidades após atualização do Vitest para 5.0.4.
- API compilada: GET /health via inject retornou 200 e contrato esperado.
- Navegador: conexão bem-sucedida, falha sem API, recuperação pelo botão Tentar novamente e layout em viewport 360px sem overflow horizontal.
- `git check-ignore`: confirmou proteção de PDF, .env e private.

O sandbox Windows restringiu resolução de caminhos do Vite/Vitest; testes e build passaram após execução autorizada fora do sandbox. Rollup emitiu avisos sobre comentários de anotação do Zod; concluiu o build normalmente.

## Como revisar

Siga os comandos e roteiro manual do README. Commit sugerido: `chore: initialize project structure`. Após autorização do primeiro commit em main, crie develop. Para futuras entregas: desenvolver em develop, executar checks e integrar à main com revisão. Não avançar à v0.2.0 sem aprovação.
